# Alex's Adventures

Tap-to-play launcher for Alex's games (Excavator Blowout, Cave Rescue, Galaxy Math, River Run, Floor Is Lava, Poopy Seagull, Bee Game, Water Pirates). Works offline after first visit. Alex's Arcade (arcade/, the 🕹️ button) lists the arcade-style games, Excavator Blowout first.
