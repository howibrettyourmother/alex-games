# Sound credits

## Intro soundtracks (hub/intro1-3.mp3)
Each intro is one pre-mixed track (loudness-normalized to about -16 LUFS, true peak under -1.5 dBTP), played with WebAudio. Tapping fades it out over 0.4 s. If nobody taps, the intro stays silent.

**Music:** "Alex Adventures" is an original theme composed for this hub. It was written programmatically as MIDI (kids-hubs/music/compose.py) and rendered with the FluidR3_GM SoundFont (MIT license) through FluidSynth. The three variations share the same brass hook with different lead voices: (1) brass + trumpets + trombones, (2) synth brass + saw lead + synth bass, (3) French horns + trumpets + choir.
